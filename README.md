## 🚀 Public Projects & Utilities

Here are some of the open tools and applications I've engineered:

### 📄 [Edip - Client-Side Native PDF Engine & Studio](https://github.com/U-Gaurav187/Edip)
> **Problem:** Heavy, paywalled, or server-dependent PDF editors that compromise document privacy and run slowly.  
> **Solution:** An Acrobat-grade, 100% client-side PDF editing studio and web engine that processes everything locally in the browser with zero server data transfer.
* **Tech:** React, Vite, Tailwind CSS, Native Web Canvas & PDF APIs, Android APK

### 🎙️ [GallaVoice (गल्ला वॉयस) - Voice Khata for Bharat](https://github.com/U-Gaurav187/GullaVoice)
> **Problem:** Retail shopkeepers struggle with complex manual accounting apps in noisy marketplace cash-counters.  
> **Solution:** A noise-resilient voice ledger designed for Indian retail environments, built for the **Scaler x Wispr Flow Hackathon**.
* **Tech:** Speech/Voice AI, React 18, Vite, Tailwind CSS

### 📶 [WifiShare - Personal Local Sharing Utility](https://github.com/U-Gaurav187/wifishre)
> **Problem:** Cumbersome multi-step cloud uploads when simply moving links and files between phones and laptops on the same Wi-Fi.  
> **Solution:** A featherweight, zero-install local network page built for personal home convenience and cross-device exchange.
* **Tech:** HTML5, Modern CSS, Client-side LAN sharing
